# Goals

## Propósito

La Feature Goals ayuda a las familias a planificar, priorizar y alcanzar sus objetivos financieros.

Un objetivo representa un estado futuro deseado que requiere decisiones sostenidas en el presente.

El propósito del sistema no es únicamente registrar el progreso económico, sino acompañar a la familia durante todo el proceso hasta la consecución del objetivo.

---

# Filosofía

Los objetivos constituyen la expresión práctica de las prioridades de una familia.

SinDescuadre entiende cada objetivo como una decisión estratégica que debe convivir con la realidad financiera actual y con el resto de compromisos existentes.

El sistema ayuda a evaluar la viabilidad, el impacto y la evolución de cada objetivo.

---

# Objetivos de la Feature

Goals permite a la familia:

- definir metas financieras;
- comprender el esfuerzo necesario para alcanzarlas;
- priorizar objetivos cuando existen recursos limitados;
- realizar seguimiento continuo;
- adaptar la planificación cuando cambia la realidad financiera.

---

# Información principal

Cada objetivo debe incluir, entre otros:

- nombre;
- descripción;
- importe objetivo;
- fecha objetivo;
- prioridad;
- categoría;
- estado de salud;
- progreso;
- impacto sobre otros objetivos.

---

# Estado de salud

Además del progreso porcentual, cada objetivo tendrá un estado de salud que refleje su situación actual.

Estados posibles:

- En buen camino.
- Requiere atención.
- En riesgo.
- Completado.

Este estado se calcula teniendo en cuenta la realidad financiera de la familia y no únicamente el dinero acumulado.

---

# Categorías

Los objetivos pueden pertenecer a diferentes categorías.

Ejemplos:

- Seguridad financiera.
- Calidad de vida.
- Familia.
- Vivienda.
- Educación.
- Inversión.
- Negocio.
- Otros.

Las categorías ayudan al sistema a contextualizar recomendaciones y establecer prioridades.

---

# Relación con el Decision Engine

El Decision Engine evalúa continuamente cada objetivo considerando:

- capacidad de ahorro;
- compromisos existentes;
- cambios de ingresos;
- gastos extraordinarios;
- conflictos entre objetivos;
- escenarios futuros.

Las recomendaciones generadas deberán explicar siempre las razones que las motivan.

---

# Relación con otras Features

Goals se integra con:

- Dashboard
- Financial Events
- Timeline
- Commitments
- Recommendations
- AI Assistant

---

# Indicadores de éxito

Una familia debería ser capaz de responder en cualquier momento:

- ¿Voy por buen camino?
- ¿Qué riesgo tiene este objetivo?
- ¿Qué decisión me acerca más a conseguirlo?
- ¿Qué ocurrirá si cambia mi situación financiera?

---

# Resumen

Goals transforma una simple lista de objetivos en un sistema de planificación financiera adaptativo, donde cada meta evoluciona junto con la realidad de la familia y recibe el apoyo del Decision Engine para facilitar mejores decisiones.
