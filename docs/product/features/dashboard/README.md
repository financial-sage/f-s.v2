# Dashboard

## Propósito

El Dashboard constituye la principal experiencia de SinDescuadre.

Su objetivo no es mostrar información financiera, sino ayudar a la familia a comprender su realidad actual y facilitar la siguiente decisión.

Cada elemento presentado debe contribuir a responder una pregunta relevante para el usuario.

---

# Filosofía

El Dashboard no es un panel de indicadores.

Es una conversación entre el sistema y la familia.

Su misión consiste en transformar información compleja en comprensión inmediata.

La familia debe ser capaz de entender su situación financiera en pocos segundos, sin necesidad de interpretar gráficos o realizar cálculos.

---



# Objetivos

El Dashboard debe permitir responder las siguientes preguntas:

1. ¿Cómo estamos hoy?
2. ¿Qué ha cambiado desde la última revisión?
3. ¿Qué requiere nuestra atención?
4. ¿Cómo avanzamos hacia nuestros objetivos?
5. ¿Cuál debería ser nuestra siguiente decisión?

---



# Organización

El contenido del Dashboard se organiza según la prioridad de las decisiones.

No sigue una estructura basada en módulos del sistema.

La secuencia propuesta es:

## Estado financiero

Resumen de la situación general.

Debe transmitir estabilidad, riesgo o mejora de forma comprensible.

---



## Cambios relevantes

Principales variaciones detectadas desde la última revisión.

Cada cambio debe incluir una explicación contextual.

---



## Objetivos

Progreso hacia las metas financieras activas.

Debe mostrar tanto el avance como la tendencia.

---



## Compromisos

Próximos eventos que requieren atención.

Incluye pagos, vencimientos y obligaciones relevantes.

---



## Próxima mejor decisión

Recomendación prioritaria generada por el Decision Engine.

Debe explicar:

- qué propone;
- por qué lo propone;
- qué impacto tendría.

---



# Principios

El Dashboard debe:

- priorizar comprensión sobre cantidad de información;
- evitar gráficos sin contexto;
- explicar las causas de los cambios relevantes;
- destacar únicamente aquello que requiere atención;
- facilitar la siguiente decisión.

---



# Relación con otras Features

El Dashboard actúa como punto de entrada al resto del producto.

Cada sección permite profundizar en otras Features cuando el usuario necesita más detalle.

---



# Indicadores de éxito

Una sesión de Dashboard se considera satisfactoria cuando la familia puede responder, en menos de un minuto:

- cuál es su situación financiera;
- qué cambios importantes han ocurrido;
- cuál es la prioridad actual;
- cuál es la siguiente decisión recomendada.

---



# Resumen

El Dashboard representa la síntesis de toda la inteligencia del producto.

No busca mostrar más información, sino ofrecer la comprensión necesaria para que la familia tome mejores decisiones.
