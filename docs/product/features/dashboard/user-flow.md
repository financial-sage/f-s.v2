# Dashboard · User Flow

## Propósito

Este documento describe el recorrido principal que realiza una familia al interactuar con el Dashboard.

El objetivo del flujo es facilitar la comprensión de la situación financiera actual y conducir de forma natural hacia la siguiente decisión relevante.

---

# Filosofía

El Dashboard constituye el punto de entrada al conocimiento generado por SinDescuadre.

La experiencia prioriza la comprensión antes que la navegación y la toma de decisiones antes que la exploración de datos.

---

# Flujo principal

## 1. Apertura

La familia accede al Dashboard.

El sistema actualiza la realidad financiera y construye una visión adaptada al contexto actual.

---

## 2. Comprensión

El Dashboard responde de forma inmediata:

- ¿Cómo estamos?
- ¿Qué ha cambiado?
- ¿Qué requiere atención?

---

## 3. Exploración

La familia puede profundizar en cualquiera de los elementos presentados.

Cada bloque actúa como puerta de entrada hacia una Feature específica.

---

## 4. Decisión

Tras comprender la situación, la familia puede:

- registrar un nuevo hecho financiero;
- revisar un objetivo;
- consultar un compromiso;
- aceptar una recomendación;
- conversar con el AI Assistant.

---

## 5. Continuidad

Una vez realizada una acción, el Dashboard se actualiza automáticamente para reflejar la nueva realidad financiera.

El ciclo comienza de nuevo.

---

# Modos de interacción

## Modo comprensión

La familia consulta el estado actual y recibe contexto.

No requiere realizar acciones.

---

## Modo acción

La familia decide actuar sobre alguno de los elementos mostrados.

Cada acción actualiza la realidad financiera y puede modificar el contenido del Dashboard.

---

# Navegación

El Dashboard actúa como punto de entrada hacia:

- Financial Events
- Timeline
- Goals
- Commitments
- Recommendations
- AI Assistant

La navegación siempre parte de una necesidad detectada, nunca de una estructura de menús.

---

# Resultado esperado

Al finalizar la interacción, la familia comprende su situación financiera y sabe cuál es la siguiente acción que puede realizar para mejorarla.

---

# Resumen

El Dashboard guía a la familia desde la comprensión de su realidad financiera hasta la acción, actuando como el centro de coordinación del resto de experiencias del producto.
