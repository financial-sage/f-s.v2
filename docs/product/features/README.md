# Product Features

## Propósito

Este documento describe qué entendemos por una Feature dentro de SinDescuadre y cómo se organiza el producto a partir de ellas.

Las Features representan las capacidades visibles que permiten a las familias interactuar con el sistema y resolver problemas concretos.

---

# Jerarquía del producto

La organización del producto sigue la siguiente estructura conceptual:

Product Vision

↓

Product Capabilities

↓

Features

↓

Experiences

↓

Components

Cada nivel responde a una pregunta diferente y complementa a los demás.

---

# Qué es una Feature

Una Feature es un conjunto coherente de funcionalidades que permite a la familia resolver una necesidad concreta relacionada con su realidad financiera.

Una Feature puede incluir múltiples experiencias, componentes y reglas de negocio.

---

# Características de una Feature

Toda Feature debe:

- resolver un problema real;
- estar alineada con una o varias Product Capabilities;
- aportar valor medible;
- integrarse con el modelo de dominio;
- evolucionar de forma independiente.

# Evolución

Las Features podrán ampliarse o dividirse conforme evolucione el producto.

La incorporación de nuevas Features deberá justificarse mediante una necesidad claramente identificada y alinearse con las capacidades fundamentales de SinDescuadre.

---

# Resumen

Las Features representan las capacidades visibles del producto y constituyen el punto de unión entre el modelo de dominio y la experiencia de las familias.
