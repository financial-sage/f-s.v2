# Register Financial Event

## Propósito

La experiencia de registro permite incorporar nuevos hechos financieros a la realidad de la familia.

Cada hecho registrado actualiza el modelo financiero y puede modificar recomendaciones, objetivos, compromisos o indicadores del sistema.

El objetivo no es almacenar datos, sino mantener una representación precisa y actualizada de la realidad financiera.

---

# Filosofía

Registrar un hecho financiero no es una tarea administrativa.

Es el momento en que la familia comunica al sistema que su realidad ha cambiado.

A partir de ese momento, SinDescuadre interpreta el impacto de ese cambio y actualiza el conocimiento disponible para la toma de decisiones.

---



# Objetivos

La experiencia debe permitir:

- registrar hechos de forma rápida;
- minimizar el esfuerzo del usuario;
- ofrecer contexto inmediato;
- actualizar automáticamente la realidad financiera;
- desencadenar los procesos necesarios del Decision Engine.

---



# Flujo

1. El usuario registra un hecho financiero.
2. El sistema valida la información.
3. Se actualiza la realidad financiera.
4. Se recalculan indicadores y objetivos.
5. Se evalúan recomendaciones.
6. Si existe un cambio relevante, el usuario recibe una explicación.

---



# Principios

La experiencia debe ser:

- rápida;
- clara;
- flexible;
- contextual;
- útil desde el primer momento.

---



# Resultado esperado

Al finalizar el registro, la familia debe comprender qué ha cambiado como consecuencia de ese hecho financiero.

El sistema debe responder inmediatamente con información útil y contextualizada, evitando limitarse a confirmar que el registro se ha guardado correctamente.

---



# Relación con otras Features

El registro de hechos financieros alimenta directamente:

- Dashboard
- Timeline
- Goals
- Commitments
- Recommendations
- AI Assistant

Constituye una de las principales fuentes de información para el modelo de dominio.
