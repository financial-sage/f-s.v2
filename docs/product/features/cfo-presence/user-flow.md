# CFO Presence — User flow

## Entrada desde Inicio

1. Usuario con acceso Premium/trial y ≥1 nota activa ve la **pastilla** (fuera del scroll).
2. Si es el primer open del día (o hay critical nueva), el **modal** de la nota primaria puede abrirse solo una vez.
3. Toque en la pastilla → navega a `/recommendations` en **Activas** (lista completa; no reabre el modal del día).
4. En el modal (auto): leer, CTA / Entendido / Más tarde / No aplica, enlace **Notas anteriores**.

## Historial

1. Desde modal o Perfil → `/recommendations` (Notas): lista de **activas**.
2. Enlace sutil **Recomendaciones anteriores** → archivo releyible (accepted / dismissed / resolved / deferred vencido reciente).
3. Releer no re-alarma; no cambia estado salvo acciones explícitas en activas.

## Guidance

El microenlace “¿Qué significa?” y `/guidance` siguen igual; no sustituyen al modal CFO.
