# CFO Presence — User flow

## Entrada desde Inicio

1. Usuario con acceso Premium/trial y ≥1 nota activa ve la **pastilla** (fuera del scroll).
2. Toque → abre **modal** con la nota de mayor prioridad (critical > important > …).
3. Si es el primer open del día (o hay critical nueva), el modal puede abrirse solo una vez.
4. En el modal: leer, CTA / Entendido / Más tarde / No aplica, enlace **Notas anteriores**.

## Historial

1. Desde modal o Perfil → `/recommendations` (Notas).
2. Pestaña **Activas**: notas `new`/`seen`.
3. Pestaña **Anteriores**: archivo releyible (accepted / dismissed / resolved / deferred vencido reciente).
4. Releer no re-alarma; no cambia estado salvo acciones explícitas en activas.

## Guidance

El microenlace “¿Qué significa?” y `/guidance` siguen igual; no sustituyen al modal CFO.
